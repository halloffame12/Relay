Build from source instead

Requires Flutter 3.41.x and the Android SDK. Run these from the repository root.

flutter pub get
flutter build apk --release --no-tree-shake-icons

For a cross-network build, point the app at your own signaling service:

flutter build apk --release --no-tree-shake-icons \
  --dart-define=RELAY_SIGNALING_URL=wss://your-host/v1/relay

Release notes

What's in 0.9.0.

  1. Reader. Offline PDF and EPUB reading with position restore, chapters, bookmarks, search and filters.
  2. QR sharing. Sender shows a single-use code; receiver scans, reviews and approves the file list.
  3. Verification. Per-file SHA-256 and byte-count checks before import, with duplicate detection and no silent overwrites.
  4. Cleanup. Cancelling or losing a connection removes temporary data and leaves no library entry.
  5. Branding. The official Relay mark across the launcher, splash, reader header and store assets.

Before you install

Three things to know.

  • This build is the same-network transfer build. The cross-network path needs a signaling endpoint and is not configured in the published APK.
  • An interrupted transfer is cancelled and cleaned up, not resumed.
  • Local TCP transfers are not transport-encrypted. Use trusted networks for sensitive documents; WebRTC paths are DTLS-encrypted.
