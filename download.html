[ INSTALLATION GUIDE ]

How to install the APK on Android.

01

Download the Release APK

Download `app-release.apk` directly from GitHub Releases to your Android device using Chrome, Firefox, or any mobile browser.

02

Enable Unknown Sources

When opening the APK, Android may ask permission to "Install unknown apps" from your browser. Allow this once in Android Settings.

03

Verify Cryptographic Hash

Optionally verify that the SHA-256 hash matches the string published on this page using any file-hash utility.

04

Open & Import

Launch Relay. Tap the `+` button in your library to import your first PDF or EPUB document from device storage.

[ RELEASE NOTES ]

What's new in v0.9.0.

  • Cross-network share subsystem: Introduced sender-owned session orchestration with single-use QR envelopes and WebRTC signaling client architecture.
  • Drift SQLite storage engine: Persists reading positions, page bookmarks, format filters, and verified transfer histories.
  • Bounded memory streaming: Streams file data in 64 KiB segments with on-the-fly SHA-256 verification and automatic `.part` file cleanup on interruption.
  • Sanitized EPUB rendering: Restricts inline media to bounded raster images (PNG, JPEG, GIF); excludes SVG and external URLs for security.
  • Hardened boundaries: JSON frames reject nesting beyond 32 levels; metadata strips control and bidi characters; manual PIN entry rotates after 5 failed guesses.
