Product

Everything you need to keep your documents close.

Relay combines a calm, offline reading library with file sharing that starts with a scan. No cloud account, no manual IP addresses, no port numbers in the normal flow.

Read anywhere

PDF and EPUB, offline.

Import once. Read on the train, in a plane, or anywhere without a connection. Relay remembers where you stopped.

  • PDF and EPUB support
  • Remembers your last position
  • Bookmarks and search
  • No network required to read
Share with a scan

A QR code is the whole handshake.

Show a code on one device, scan it with the other. Approve the incoming files before a single byte is written.

  • Single-use, short-lived codes
  • Receiver approval required
  • Integrity verified per file
  • No manual pairing codes in the normal flow
Across networks

Designed for the messy real world.

Relay prefers a direct connection and falls back to a relay only when it has to. You never type an IP address or a port.

  • Direct device-to-device when possible
  • Relayed connection as fallback
  • Automatic connection selection
  • Clear status of which path is used

Cross-network transfer requires a deployed signaling service and is labeled honestly in the app when unavailable.

Privacy

Your documents should stay yours.

Relay keeps your library on the device and never auto-accepts a file. Direct transfers move between devices without a cloud relay. Cross-network transfers may use a relay only when a direct path is unavailable, and that relay sees encrypted packets, not file contents.

Relay does not claim end-to-end encryption for the local network path, and it does not upload your documents to cloud storage.
