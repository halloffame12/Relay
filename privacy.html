Privacy Policy

Last updated: November 2026. How Relay handles documents, network sockets, and device permissions.

1. Local Storage Architecture

Relay is an offline-first application. All imported PDF and EPUB documents, reading positions, bookmarks, and transfer logs are stored strictly on your local device in an embedded SQLite database (Drift). Relay operates no cloud storage servers, user accounts, or remote document synchronizers.

2. Document Transfer & Network Data

Relay facilitates peer-to-peer file transfer between devices using local TCP sockets or WebRTC data channels:

  • Local Wi-Fi Transfers: Transmit directly between the two local IP addresses on your Wi-Fi network. File bytes travel directly between the two devices and never exit your local network router. Note that raw local TCP transmissions are unencrypted at the transport level; do not transfer sensitive documents across untrusted or public Wi-Fi networks without an isolated guest boundary.
  • Cross-Network / WebRTC Transfers: When devices reside on disparate networks, Relay negotiates a peer-to-peer connection via a lightweight WebSocket signaling service. Session SDPs and ICE candidates are exchanged to coordinate NAT traversal. WebRTC data channels are encrypted using DTLS. Relay does not store or log file contents on signaling servers.

3. Device Permissions

Relay requests minimal Android operating system permissions:

  • Camera: Requested strictly and exclusively while the QR code scanner is active to scan the peer's invitation token. Camera frames are parsed in memory and never recorded, saved, or uploaded.
  • Storage / Media: Utilizes the standard Android system file picker (Storage Access Framework) to import documents. Relay only reads files you explicitly select and writes to its own sandboxed application directory.
  • Network: Required to establish local Wi-Fi TCP sockets and connect to the signaling coordinator when performing cross-network transfers.

4. Analytics & Tracking

Relay contains zero advertising SDKs, zero behavioral trackers, and zero third-party analytics libraries. We do not track what you read, how long you read, or with whom you share documents.

5. Contact

For questions regarding Relay's privacy practices or security architecture, you may inspect the open source code on GitHub or contact the development team at support@relay-reader.org.
