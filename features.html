Features

What Relay actually does.

A short, honest list. No promised capabilities that are not in the app.

Reading

PDF reader

Open PDFs from your library, restore your last position, add bookmarks, and read without a connection.

  • Page navigation and last-position restore
  • Bookmarks
  • Works fully offline
Reading

EPUB reader

Read EPUBs with chapter navigation, inline images, and position restore.

  • Chapter navigation
  • Bounded inline images (PNG, JPEG, GIF)
  • SVG and remote images are skipped for safety
Library

Offline library

Import PDFs and EPUBs through the system picker. Relay copies them into app-managed storage, computes SHA-256, and rejects duplicates.

  • Search and filter by format and reading status
  • Storage usage visibility
  • Remove Relay's copy without touching the original file
Sharing

QR pairing

One device shows a QR code, the other scans it. Codes are single-use and short-lived. Manual address, port and code entry remain as a fallback.

  • Single-use, expiring codes
  • Camera permission requested only when scanning
  • Scanned text is never opened as a URL
Sharing

Cross-network transfer

Designed to work without both devices sharing the same Wi-Fi. Direct connection first, relay fallback when needed. No manual network configuration.

  • Automatic connection selection
  • Clear indication of which path is used
  • Requires a deployed signaling service to be enabled
Integrity

Verification and duplicates

Every incoming file is checked against its declared size and SHA-256 before import. A duplicate is reported without overwriting the existing document.

  • SHA-256 verification
  • Declared byte count checked
  • Interrupted transfers leave no entry
Organization

File organization

Search, filter and sort your library. See how much storage Relay uses. Open documents where you left off.

  • Title, author and source search
  • Format and reading-status filters
  • Sort by title or size
