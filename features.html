[ SYSTEM SPECIFICATIONS ]

What Relay actually does.

A verified, exhaustive account of all features genuinely implemented in Relay v0.9.0. No exaggerated claims, no unverified marketing promises.

[DOCUMENT ENGINE]

PDF Reading Engine

A fast, distraction-free document viewer designed for reading papers, articles, and long-form manuals completely offline.

Continuous Rendering

Smooth vertical scrolling with page boundary indicators and immediate page jump navigation.

Position Persistence

Relay remembers your exact scroll coordinate and page index, restoring your reading position on reopen.

Custom Bookmarks

Add named bookmarks to critical references and retrieve them from the document drawer.

Zero Network Leaks

Never fetches remote fonts, telemetry, or external web assets while opening or viewing documents.

[DOCUMENT ENGINE]

EPUB Reader with Bounded Media

A sanitized EPUB reading experience that protects device memory and preserves battery life.

Sanitized HTML Flow

Strips control characters, bidi overrides, and unsupported HTML tags before rendering chapters.

Bounded Inline Images

Renders chapter-relative PNG, JPEG, and GIF images within strict budgets (8 MiB per image, 24 MiB per book).

Safety Safeguards

SVG files and remote web URLs are deliberately skipped to prevent tracking pixels and script execution.

Chapter Indexing

Fast table-of-contents navigation with progress tracking per chapter.

[STORAGE ARCHITECTURE]

Local-First Offline Library

Your documents are managed locally through an embedded SQLite database powered by Drift, completely detached from cloud services.

System Picker Import

Import any PDF or EPUB using Android's system storage framework. Relay copies the file to app-managed storage.

Original File Protection

Removing a managed document inside Relay never alters or deletes the original file in your Downloads folder.

SHA-256 Deduplication

Computes checksum on import; duplicate files are detected and rejected to save storage space.

Storage Transparency

Inspect exact byte counts and disk space consumed by individual documents and the entire library.

[NETWORKING PROTOCOL]

QR Pairing Protocol v2

Camera-assisted peer pairing that eliminates typed IP addresses, port numbers, and network setup menus.

Ephemeral QR Invitations

Payloads contain short-lived cryptographic tokens with a hard 10-minute expiry cap.

Binary Protocol Verification

Scanned text is parsed strictly through Relay's frame decoder and never opened in a web browser.

Hardware Camera Boundary

Camera permission is requested exclusively when activating the QR viewfinder and closed immediately after.

Manual IPv4 Fallback

Expandable drawer displays manual IP, port, and one-time 6-digit PIN if camera hardware is unavailable.

[NETWORKING PROTOCOL]

Cross-Network Peer Transfer

Engineered to negotiate connections across disparate Wi-Fi routers, guest networks, and mobile data.

LAN-First Negotiation

Attempts direct high-speed local TCP connection first to minimize latency and bypass external servers.

WebRTC Data Channels

Falls back to WebRTC peer-to-peer data channels when devices are separated by restrictive NATs.

Signaling Reference Client

Connects to a lightweight WebSocket signaling service to exchange session SDPs and ICE candidates.

Honest Availability State

Clearly indicates in UI whether cross-network relaying is available or restricted to local LAN.

[SECURITY & SAFETY]

Integrity Verification & Consent

Every transferred document undergoes cryptographic checksum validation and explicit receiver approval.

Blocking Approval Dialog

Receiving device must explicitly confirm file acceptance. No auto-downloading or unsolicited delivery.

On-the-Fly SHA-256 Check

Calculates digest incrementally as bytes arrive. Files with mismatched checksums are deleted instantly.

Bounded Memory Streaming

Streams in 64 KiB buffers to keep memory footprint flat regardless of whether the file is 2 MB or 100 MB.

Duplicate Integrity Gate

If the receiver already possesses an identical file, Relay alerts the user without duplicating data.

[LIBRARY MANAGEMENT]

Organization & Search

Fast filtering, search, and sorting tools to navigate large offline book and document collections.

Full Title & Author Search

Search instantly across document titles, authors, and metadata stored in Drift SQLite.

Format Filtering

Filter library views between PDF, EPUB, or all formats with one tap.

Reading Status Badges

Track which documents are unread, in-progress, or finished with clear visual badges.

Sort Controls

Sort your collection by title, import date, file size, or recent reading activity.
